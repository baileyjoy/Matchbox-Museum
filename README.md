# Matchbox-museum
---- About the Project ----
Matchbox museum is a small website inspired by vintage matchbox designs and packaging. I wanted to create a fun digital collection that shows off the different colors, illustrations, and styles I found on old matchboxes.

This website uses a vintage inspired color pallette with reds, yellows, and teal to give it a retro look.

--Code Defense---
For this project, I used a selective CSS reset instead of removing all default browser styles. This helped keep the styling consistent while still preserving useful features like keyboard focus indicators. 
I organized my CSS using design tokens for color, fonts, and spacing. The tokens made it easier to keep the design consistent and make changes without having to edit individual CSS rules.
